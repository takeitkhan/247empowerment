## 🔑 The Three Types of IDs You Might See

### ✅ **API Key** (THIS ONE!)
```
sk-proj-1234567890abcdefghijklmnopqrstuvwxyz
└─ Always starts with "sk-" or "sk-proj-"
└ This is your authentication key
└ Format: ~80+ characters
└ REQUIRED for our plugin
└ NEVER share publicly
```

**Where to find:**
- OpenAI Dashboard → API Keys
- Shown only once after creation
- Must copy immediately
- Can create new ones anytime

---

### ⚠️ **Organization ID** (OPTIONAL - Rarely Used)
```
org-1234567890abcdefghijk
└─ Starts with "org-"
└ For multi-organization accounts
└ Used to route billing/requests
└ Most users don't need this
└ Leave empty if unsure
```

**When needed:**
- Multiple organizations in OpenAI
- Want to bill to specific org
- Enterprise accounts
- Don't use if you're unsure

---

### ❌ **Tracking ID** (NOT FOR US)
```
tracking-id-12345
└─ Shown in API responses
└ For tracking requests
└ Generated by OpenAI
└ You CAN'T use this for auth
└ Just informational
```

**Why you see it:**
- Shows up in response headers
- Useful for OpenAI support
- Not for authentication
- IGNORE for our plugin

## 🎬 Step-by-Step to Get Your API Key

### Step 1: Log In to OpenAI
```
1. Visit: https://platform.openai.com/login
2. Enter email and password
3. Complete 2FA if enabled
4. You're in! ✅
```

### Step 2: Find API Keys Section
```
Desktop:
1. Click your avatar (bottom left)
2. Select "Account"
3. Click "API keys" in sidebar
4. Now you see the list

Mobile:
1. Tap menu (≡)
2. Find "Account"
3. Tap "API keys"
4. Now you see the list
```

### Step 3: Create New Key
```
1. Click [Create new secret key]
2. Optional: Name it (e.g., "WordPress Chat")
3. Click [Create secret key]
4. KEY APPEARS! ⚠️ Copy NOW
5. Paste into WordPress setting
6. Click [Done]
```

### Step 4: Paste in WordPress
```
1. Go to: WordPress Admin > AI Chat > Settings
2. Find: "OpenAI API Key" field
3. Paste: sk-proj-xxxxxxxxxxxxx
4. Click: [Test Connection]
5. Should show: ✅ "Valid and working"
6. Click: [Save Settings]
```

## 🔍 How to Identify What You Have

### Does it look like this?
```
sk-proj-abcdefghijklmnopqrstuvwxyz123456789
```
✅ **CORRECT** - This is an API Key! Use it!

### Does it look like this?
```
org-abcdefghijklmnopqrst
```
⚠️ This is Organization ID - You probably don't need it, but it's okay to ignore

### Does it look like this?
```
abc-123-def-456
```
❌ **WRONG** - This doesn't match any OpenAI key format

## ⚠️ If You're Confused

**If you see multiple IDs and don't know which:**

1. **First choice**: Copy anything starting with `sk-`
2. **Second choice**: If there's a field labeled "API Key", that's it
3. **Third choice**: If nothing with `sk-`, go back and create a new key
4. **Test it**: Paste in WordPress and click "Test Connection"

**If test fails:**
- You probably have the wrong key
- Go back and try finding the one starting with `sk-`
